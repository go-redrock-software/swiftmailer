# Opportunistic STARTTLS (auto_tls) — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add opportunistic STARTTLS support to `EsmtpTransport` so it automatically upgrades to TLS when the server advertises STARTTLS, without requiring explicit `setEncryption('tls')`. Controlled by an `auto_tls` property (default: `true`). Matches Symfony Mailer 7.1's `auto_tls` DSN parameter.

**Architecture:** Add `$autoTls` property to `EsmtpTransport`. During `doHeloCommand()`, after parsing EHLO capabilities, if `autoTls` is true and the server advertises `STARTTLS` and encryption was NOT explicitly set, attempt STARTTLS opportunistically (don't fail if it fails). Support `auto_tls` DSN parameter in `DsnTransportFactory`. The existing `peer_fingerprint` and `verify_peer` DSN parameters are already implemented.

**Tech Stack:** PHP 8.1+, existing SwiftMailer ESMTP layer. No new dependencies.

**Step 2: Implement opportunistic STARTTLS**

Read `lib/classes/Swift/Transport/EsmtpTransport.php` around line 344-380 (the `doHeloCommand()` method).

Current code structure:
```php
protected function doHeloCommand()
{
    // EHLO
    // If explicit STARTTLS: issue STARTTLS, startTLS(), re-EHLO
    // Parse capabilities
}
```

After the explicit STARTTLS block (the `if ($this->params[CONNECTION_ENCRYPTION_MODE_STARTTLS])` block ending around line 374), and after capabilities are parsed (line 376), add an opportunistic STARTTLS block:

```php
        // Opportunistic STARTTLS: if auto_tls is enabled, no explicit encryption,
        // and server advertises STARTTLS, attempt upgrade silently.
        if ($this->params['auto_tls']
            && !$this->params[CONNECTION_ENCRYPTION_MODE_STARTTLS]
            && 'tcp' === $this->params['protocol']
            && isset($this->capabilities['STARTTLS'])
        ) {
            try {
                $this->executeCommand("STARTTLS\r\n", [220]);

                if ($this->buffer->startTLS()) {
                    // TLS upgrade succeeded — re-EHLO to get updated capabilities
                    try {
                        $response = $this->executeCommand(
                            \sprintf("EHLO %s\r\n", $this->domain),
                            [250],
                        );
                        $this->capabilities = $this->getCapabilities($response);
                    } catch (Swift_TransportException $e) {
                        // Re-EHLO failed, but TLS is active — continue with original capabilities
                    }
                }
            } catch (Swift_TransportException $e) {
                // STARTTLS failed — continue unencrypted (opportunistic)
            }
        }
```

**Important:** This block must go AFTER the capabilities parsing (`$this->capabilities = $this->getCapabilities($response);` around line 376) but BEFORE the handler activation code.
