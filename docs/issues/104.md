# Issue #104: Sync Swift::VERSION with the latest release tag

**Branch:** fix/104-sync-version-with-release-tag
**Issue:** https://code.go-redrock.com/trac/swiftmailer/-/work_items/104

## Design

Set `Swift::VERSION` to the latest released tag (`6.5.8`). Add a test for the rule that the latest reachable `v*` tag must equal the constant, so a release commit has to bump the constant before it is tagged. No tags are created or moved. Explicit release versioning and the tag-time gate stay with #92.

## Implementation

- `lib/classes/Swift.php`: `VERSION` changes from `6.5.0` to `6.5.8`. Nothing in lib/, bin/ or tests/ read the old value.
- `SwiftTest::testVersionMatchesLatestReachableReleaseTag()`: compares `git describe --tags --abbrev=0 --match "v[0-9]*"` with the constant. The test skips when the checkout has no tags. CI uses a shallow, tagless clone, so the test runs locally and in full-history checkouts.
- CHANGES: corrected the note about the v6.5.1 to v6.5.8 tags, and added a Bug Fixes entry.
