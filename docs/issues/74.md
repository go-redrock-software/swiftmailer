## Design

## Implementation Plan

### Approach
Implement the six broken plain-HTTP provider DSN routes under #30 on top of !29. Fix the associated confidential SDK construction/error-trace bug #75 without inventing SDK authentication contracts. Preserve literal-zero API credentials by null presence.

### Changes
- Mailgun `KEY:DOMAIN@default`, optional `region=us|eu`, or explicit HTTPS endpoint authority/path. Mailjet `PUBLIC:PRIVATE@default`. Scaleway `PROJECT_ID:API_KEY@default`, default/explicit `region=fr-par` (the provider currently documents only Paris for Transactional Email).
- Infobip and Postal require a real endpoint host; preserve port and optional base path, force HTTPS and retain the existing public-endpoint URL guard. Default-host placeholder is invalid. Mailgun custom endpoints use the same guard. Reject fragments and misleading endpoint overrides on fixed-endpoint routes.
- Live Mailtrap uses its actual constructor. Sandbox retains host-ID and `inbox_id` forms, requires a positive decimal inbox ID, rejects conflicting IDs and applies canonical scalar/duplicate validation. `region` is exclusive to Mailgun/Scaleway; `inbox_id` is exclusive to sandbox. Reuse configured query separator validation.
- Reject gmail+api, microsoft-graph, amazon+api and amazon+http before credential strings reach SDK constructors. Static credential-safe errors; direct native SDK construction remains supported.
- Add constructor-to-wire regression coverage, missing/invalid/ambiguous options, credentials/zero values, public helper/wrappers, errors/redirect behavior, endpoint guard and trace redaction. Update DSN docs, #30 requirements and handoffs.

### Acceptance Criteria
All six providers construct and use correct credentials, endpoints and provider-specific inputs in real Guzzle requests with synthetic handlers; no external email. Invalid routes/settings reject without credential-bearing factory traces. Existing working API transports and SMTP controls remain intact. Focused failing-before tests and manual mutations, full PHP 8.3/8.5 suites, PHPStan/style/Composer/map/alias/diff checks and six required exact-final-head CI checks. No dependency/vendor changes, new baseline suppressions, threshold reductions or merge. #30 remains open for SDK construction and broader metadata/options work.

### Sources and Risks
Context7 `/symfony/symfony-docs` documents provider DSNs. Official Symfony 7.4 Mailgun/Scaleway factories establish credential order; Scaleway Transactional Email API docs state availability in `fr-par` only. The fork's actual constructors are authoritative. Custom endpoint paths/ports must survive without introducing userinfo/query/fragment ambiguity or bypassing existing private-host restrictions. Fixed-endpoint providers continue using their native endpoints. Existing generic API routes retain ignored-host compatibility.
