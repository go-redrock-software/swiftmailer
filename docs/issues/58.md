## Design

### Approach
Branch `fix/58-isolate-graph-sdk-requests` from !18 at `b4c056cce2152336ecdeb1c0f08985c424d73d67`, reusing its operation-scoped NoRedirectClient and existing non-retryable marker. Protect all Graph resource requests made by a public Swift send, including draft attachment uploads and calendar operations, while leaving the caller Graph client/adapter/HTTP configuration intact.

The installed Kiota GuzzleRequestAdapter has no public getter/setter/factory for replacing only an already configured HTTP client. Its typed RequestInformation options cannot directly carry ordinary Guzzle redirect options. Rebuilding authentication/serialization manually would discard configured behavior. Use one checked compatibility helper that clones a standard GuzzleRequestAdapter and replaces only the copy's private guzzleClient field with NoRedirectClient via ReflectionProperty. Retain the original authentication provider, serialization/parse factories, telemetry/tracer, CAE logic, base URL and cache objects. Build operation-local generated request builders from that adapter. No caller-owned object is temporarily rewritten. Unsupported/non-cloneable/uninitialized adapters must fail clearly with the non-retryable marker before network traffic; future SDK field changes fail closed.

A local real-SDK probe confirms this boundary: previously Graph send followed 307 and reported two accepted recipients; the cloned adapter now issues one request and raises a Swift transport exception wrapping the non-retryable marker. The original HTTP object, full defaults and handler-stack string remain identical.

### Changes
- Add a small Graph adapter compatibility helper and metadata/alias registration. Keep vendor-private access in one documented place with explicit checks and tests.
- Resolve mail and calendar user builders using the scoped adapter; cover sendMail, draft creation, small attachments, upload-session creation, draft send, event lookup/create/update/cancel.
- Ensure LargeFileUploadTask uses the same operation adapter and redirect latch. Preserve existing protected helper signatures/subclass hooks; use request/session identity to carry context without a globally swapped caller client. Keep callbacks, events, explicit envelope policies and cleanup on the original Swift transport.
- Retain ordinary SDK response decoding, authentication (including CAE), retries and success counts. The existing Graph exception wrapper may retain the marker in its cause chain; default Swift retries must not replay redirects. Health ping is local-only, so it must remain network-free.
- Replace affected builder-mock send assertions with real SDK/HTTP fixtures, preserving their behavioral coverage. Add failing-before/fixed-after real middleware tests covering all redirect statuses, destinations, default and caller retry middleware, draft/upload/calendar stages, success/error controls, caller state, reentrancy and policies.
- Document the compatibility boundary, generated-builder behavior and independent SDK scope. Graph OAuth token requests use a separate HTTP client and are not covered by swapping the resource adapter; assess independently and track a separate confirmed finding if needed. SES #59 remains separate.

### Acceptance Criteria
- With redirect-enabled injected defaults, every Graph resource request stays at its original target; no follow-up request or automatic Swift/SDK replay occurs on 3xx. No redirected send reports accepted recipients.
- An interrupted draft/upload/calendar flow sends no later dependent requests. Successful large attachment and calendar flows still work through real SDK serializers/adapters.
- Original Graph client/adapter identity, HTTP defaults/stack, base URL, auth provider/cache and unrelated subsequent caller requests retain their behavior. Callback/event transport identity remains the original Swift instance; policy-modified recipients are restored on all exits.
- Supported real Guzzle adapters preserve authentication/CAE and ordinary retry/error behavior. Unsupported adapters fail before wire requests. Custom adapters/SDK overrides are documented precisely rather than silently bypassing policy.
- Local-only ping stays network-free. No OAuth-wide or all-SDK guarantee is claimed without evidence.
- Full PHP 8.3 and 8.5 suites, PHPStan, full style, strict Composer validation, whitespace checks and exact-final-head required CI pass. No baseline/threshold/vendor edits; publish a reviewable MR targeting !18, update the board and do not merge.

### Risks
Private Kiota field access is a compatibility constraint, bounded by instance/field/type/clone checks and fail-closed tests. Standard adapter subclasses retain their state, but arbitrary overrides must honor the Guzzle/SDK contract. Caller custom GraphServiceClient builder overrides are not reproduced when standard operation-local generated builders are created; document this supported contract. Protected upload helper signatures remain intact. Resource requests and OAuth token exchanges have separate HTTP ownership boundaries; do not conflate them. Optional CI prerequisites #38/#40/#45/#46 remain separate.
