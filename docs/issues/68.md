## Implementation Plan

### Approach
Repair pool lifecycle ownership independently of timed recovery. Forward plugins to active and inactive configured backend identities, restore dead entries once, and ensure the backend selected for ping/send occupies the position removed by the existing protected retirement hook.

### Changes
- `LoadBalancedTransport::registerPlugin()` visits active plus dead backends once per object identity, using an operation-local inventory snapshot.
- `start()` clears restored dead entries so repeated starts preserve configured multiplicity without growth.
- Round-robin `ping()` uses bounded normal selection/rotation so false checks retire the backend actually probed. Guard caller configuration versions around callbacks; retain normal healthy order and protected signatures.
- Failover repositions its cached backend when restoration appended other entries, preserving sticky selection and correct retirement/fallback.
- Add real HTTP policy-restoration tests plus lifecycle/inventory/health/failover regressions, including duplicate references and reentrant configuration; document the behavior and limitations.

### Acceptance Criteria
- Demonstrate failing-before policy bypass after failure -> plugin registration -> restoration, with allowlist/catch-all/redirect policies, implicit/explicit envelopes, successful and failing restored sends, message restoration and events. Preserve injected dispatchers and terminal-failure rules from !24.
- A failed ping never retires a healthy unprobed backend; mixed/all-good/all-bad pools are bounded and retain the expected order. Failover retires its selected cached backend after restoration.
- Repeated starts restore each configured entry once; intentional duplicate references retain their configured weight. Register each plugin once per backend identity, including dead backends, nested wrappers and later caller replacement.
- Full PHP 8.3/8.5 suites, PHPStan, style, Composer/map/alias/diff checks and six exact-head required CI jobs. No dependency/vendor/baseline/threshold changes. Base on !24; no merge.

### Scope and Risks
This repair precedes #29/#31 retry-period work and does not change current manual-restart defaults. Unknown custom transport overrides still own their behavior. Preserve protected lifecycle signatures and sticky failover selection; do not reset caller-owned HTTP clients or duplicate listeners when a backend appears multiple times.
