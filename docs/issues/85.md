## Implementation Plan

### Approach
Detach Graph SDK send failures at the existing catch boundary into static Swift failures with safe numeric HTTP/exception metadata and no unsafe SDK message/previous cause. Preserve terminal markers and PHP Error causes using a nonretryable Swift class. Read Kiota ApiException responseStatusCode and Guzzle response status before falling back to safe numeric exception codes, including nested failures. Preserve HTTP 500 transient classification with a static internal-server-error phrase. If metadata inspection itself fails, refuse permanently rather than exposing the new SDK error.

### Changes
Add a focused failure adapter to GraphRequestPolicy and replace the unsafe MicrosoftGraphTransport catch wrapper. Update legacy tests deliberately for detached diagnostics and corrected 401/403 retry decisions; keep generic Swift cause support and existing event/cancellation semantics. Add isolated graph/message/trace privacy tests across real OAuth contexts and resource/token failures, advanced Graph stages, default and forced retry controls, safe nested metadata and caller ownership. Update API/security docs and #30's prerequisite audit map.

### Acceptance Criteria
Real Microsoft Graph/Kiota/League/Guzzle fixtures reproduce unsafe graphs/provider messages and lost Kiota HTTP codes before the fix. Messages, string traces and printed exception objects must not retain fabricated credential/provider markers with argument recording on/off. Correct status/terminal/default retry results for resource and OAuth failures; default auth failures do not automatically resend. Existing SDK retries remain functional. Redirect/Error hard failures cannot lose their marker after detachment, including across wrappers. Draft/upload/calendar paths, completion/failed-recipient cleanup and caller clients/options remain intact. Full PHP 8.3/8.5, PHPStan/style/Composer/map/alias checks, focused manual mutations and final-head required CI pass; optional results recorded accurately. No dependency/vendor/baseline/threshold changes or GitLab merges.

### Risks and Sources
SDK-specific messages/previous causes intentionally change to protect OAuth credentials; use safe Swift codes/terminal classification instead. Shared classifier rules outside this status-loss bug remain unchanged. Caller-owned trace frames/callback logging remain caller-controlled. Graph DSN construction and its acceptance audit remain open under #30; this work supplies a safe failure prerequisite. Context7 official Graph PHP documentation and installed Kiota ApiException/Guzzle adapter sources establish responseStatusCode versus Exception code semantics.
