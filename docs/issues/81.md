## Implementation Plan

### Approach
Extend the existing operation-local Guzzle redirect guard with an optional request-aware response validator. A Gmail policy validates only successful POST users/me/messages/send responses before Google model hydration and before caller/SDK retry processing. Buffer valid bodies for nonseekable SDK decoding. Latch malformed/incomplete/interrupted acceptance, reassert after swallowed failures and reject SDK results without observed valid acceptance. Token exchanges and ordinary errors keep SDK handling.

### Changes
Add a small Gmail acceptance policy and register its class/alias; adapt GoogleTransport and the scoped HTTP helper. At the public Gmail boundary detach terminal SDK failures into static Swift nonretryable exceptions with safe numeric codes and no previous cause; ordinary Exceptions retain zero return. Add real SDK/Guzzle wire, middleware, refresh, stream, wrapper, lifecycle/ownership and isolated graph regressions. Update API/security docs and #30 audit map.

### Acceptance Criteria
Failing-before/fixed-after proofs for false acceptance and credential-bearing graphs. Malformed/missing/nonstring/empty/whitespace/control IDs and interrupted known-2xx bodies cannot claim success or replay through forced retry/failover/roundrobin, SDK retry or caller middleware. Valid nonempty string IDs including zero pass. One operation refusal does not poison later explicit sends. Caller HTTP/config/cache/defer state and refresh/MIME/policy/event behavior remain intact. Full PHP 8.3/8.5, quality/map/alias checks, focused mutations and exact-final-head required CI pass; optional jobs recorded accurately. No dependency/baseline/threshold changes or GitLab merges.

### Risks and Sources
Strict acceptance deliberately changes prior false-success/ordinary-zero cases into permanent ambiguous delivery failures. SDK-specific terminal error messages/causes intentionally change to protect OAuth data. Google SDK customizations must perform the guarded immediate send and return a valid Message. Public docs cover behavior; confidential issue retains diagnostic reproduction. Sources: official Gmail users.messages.send and Message reference; installed Google REST decoder/model source and Context7 current client documentation. This work does not complete #30 Google/Graph construction.
