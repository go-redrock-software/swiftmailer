## Implementation Plan

### Approach
Construct real Google Gmail clients for two explicit authentication forms: gmail+api://ACCESS_TOKEN@default for caller-managed bearer tokens, and gmail+api://CLIENT_ID:CLIENT_SECRET@default?refresh_token=TOKEN for renewable OAuth. Use Google's explicit UserRefreshCredentials provider in refresh mode so refresh capability survives SDK token callbacks/cache renewal and literal-zero credentials avoid the SDK helper's truthiness filtering. Fix Gmail scope/universe/endpoints, disable ADC and make no constructor network calls. Service-account/managed credential setup remains native SDK configuration.

### Changes
Add a sensitive optional gmailHttpClient Guzzle constructor parameter after the existing SES parameter. Validate canonical/scoped scalar refresh_token exactly once, fixed default endpoint and unambiguous userinfo modes. Validate bearer token/header grammar and visible-ASCII OAuth fields, preserving literal/encoded zero. Construct explicit credentials and a real Google Client with gmail.send scope, googleapis.com universe and no ambient credentials; detach constructor failures statically. Retain native Gmail redirect/acceptance/failure/privacy/MIME/events, wrappers and caller-owned HTTP options. Update provider tables/examples and #30 audit map.

### Acceptance Criteria
Failing-before/fixed-after construction tests and real synthetic Google SDK/Guzzle wire evidence for both auth modes. Exact OAuth form fields and Bearer headers, refreshed token caching and renewal across repeated sends, literal/encoded zero and reserved credentials, ambient isolation, fixed endpoints and no construction I/O. Invalid/duplicate/aliased/array/scoped options and malformed endpoint/userinfo reject without unsafe causes or own factory trace inputs. Guards remain effective through direct/wrapped/helper use, redirects, malformed/interrupted acceptance, SDK/caller retries and policies/events/MIME. Full PHP 8.3/8.5, static/style/Composer/map/alias checks and focused manual mutations; final-head required CI pass, optional results recorded. No dependency/vendor/baseline/threshold changes or GitLab merges. #30 stays open for Graph and remaining audit.

### Risks and Sources
Bearer mode sends the supplied token and does not infer its remaining lifetime or refresh it; use renewable OAuth for persistent services. Refresh mode uses an explicit provider rather than placeholder expired access tokens, so subsequent renewal does not depend on the default SDK callback retaining refresh_token. Fixed host/scope/universe avoid untrusted endpoint and ambient credential selection. Injected HTTP must satisfy the existing Guzzle scoped-client contract; native SDK configuration remains available for advanced authentication. Official Context7 Google client construction/auth documentation and installed Google Client/UserRefreshCredentials/auth middleware sources establish behavior; real HTTP fixtures verify it.
