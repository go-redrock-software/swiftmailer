## Design

## Implementation Plan

### Approach
Add the tracking controls requested in #15 through SendGrid HTTP transport accessors and DSN parameters. Match the official v3 Mail Send `tracking_settings` JSON fields. Preserve existing payload behavior when no setting is supplied.

### Changes
- Add nullable boolean defaults, getters and fluent setters for click tracking (`click_tracking.enable`), plain-text click tracking (`click_tracking.enable_text`) and open tracking (`open_tracking.enable`). Null omits the individual field; false must remain a JSON boolean, and setters can reset to null between sends.
- Accept leaf DSN options `click_tracking`, `click_tracking_text` and `open_tracking` for the `sendgrid` HTTP scheme. Accept case-insensitive true/false or 1/0; reject empty, array, duplicate, normalized alias and malformed values with static errors that omit credentials/values. Reject these options on other schemes so they cannot appear to disable tracking on unsupported transports. Preserve per-leaf retry and pool wrappers.
- Keep constructor, injected client/dispatcher, recipient/envelope policies, attachments, tags and metadata unchanged. No per-message control-header protocol or general provider settings escape hatch is introduced; the requested DSN configuration route is implemented directly.
- Add failing-before wire-level regression tests using real Guzzle clients and synthetic HTTP handlers. Cover all 27 nullable setting combinations, runtime resets/reuse, boolean DSN values, strict rejection, wrapper combinations, provider scope, message reuse and recipient policies/events. Update provider and DSN docs with account-default/omit behavior and plain-text flag scope.

### Acceptance Criteria
- Unconfigured requests omit tracking_settings; individual flags serialize to their documented nested fields without truthiness filtering. Mixed settings, explicit false and reset-to-null behave correctly on successive sends.
- DSN construction produces the same behavior as direct accessors, including false and encoded values, with leaf options preserved inside retry/pool wrappers. Invalid options throw before any send, without credential-bearing error messages or own trace arguments; unsupported providers reject the new options.
- Existing recipient safety, explicit envelopes, error/redirect handling, injected dependencies and message cleanup remain intact.
- Full PHP 8.3/8.5 suites, PHPStan, style, Composer/map/alias/diff checks and six required exact-final-head CI jobs pass. Record optional CI limits accurately. No dependency/vendor/baseline/threshold changes or merge.

### Sources and Risks
Official [Mail Send API](https://www.twilio.com/docs/sendgrid/api-reference/mail-send/mail-send) defines the three optional booleans; [tracking settings](https://www.twilio.com/docs/sendgrid/ui/account-and-settings/tracking) distinguishes plain-text click tracking. Context7 resolved the official SendGrid reference but both documentation queries returned no matches (no quota failure), so Firecrawl retrieved the official pages. Local source and wire-level tests determine compatibility.

Omission preserves the current provider request; it does not promise a provider-account default value. enable_text is a separate flag, useful with click tracking enabled; callers can configure it independently. No production provider request or external email is used for testing. Base on !26 to retain the completed pool/DSN and recipient-security stack.

## Implementation

### Changes

- Added nullable `get/setClickTracking`, `get/setClickTrackingText` and `get/setOpenTracking` accessors to the SendGrid HTTP transport. Defaults omit every tracking field; explicit false serializes as a JSON boolean; null removes an override for later sends. Constructor and dependency ownership are unchanged.
- Added SendGrid-only leaf DSN parameters `click_tracking`, `click_tracking_text` and `open_tracking`, supporting true/false (case-insensitive) or 1/0 after URL decoding. Reject duplicate, array, normalized-alias, empty and malformed values, plus unsupported schemes, using static credential-free messages. Both inputs to the new validation helper are sensitive trace parameters.
- Kept flags independent and mapped to the provider's exact nested fields. No local link rewriting, tracking pixel insertion or message-header control protocol is added. Existing retry and pool decorators retain settings on their leaves.
- Added `SendgridTrackingTest.php` and updated provider/DSN docs, including reset-to-null, plain-text behavior and transport-wide scope.

### Validation

- Initial failing-before run: **85 cases, 62 errors and 22 assertion failures**, with one unchanged-request control passing. Final new regressions: **86 tests, 584 assertions**, all passing. A trace diagnostic was bounded to the factory's own three frames to avoid traversing PHPUnit's entire object graph.
- All 27 nullable flag combinations are checked against actual serialized requests through real Guzzle clients with synthetic responses. Tests cover dependency identity, authorization and redirect policy, runtime reuse/reset, 24 valid DSN boolean cases, four decorator combinations, 17 invalid inputs with own-frame trace privacy, five unsupported schemes and a real transient HTTP retry.
- Six implicit/explicit-envelope policy cases retain allowlist, catch-all and redirect behavior, before/after send events, message restoration, failed-recipient state and active-envelope cleanup. No production provider call or email was used.
- **14/14 focused manual mutations detected by assertion failures**, sometimes alongside missing-wire-field test errors: each false flag, text field mapping, default omission, runtime reset, factory false/text handling, string truthiness, duplicate/name validation, provider scope and both helper trace arguments. Original source snapshots restored; this is not an Infection MSI score.
- Focused provider/factory/conformance run: **339 tests / 1,024 assertions**, passing. Full PHP 8.5: **8,167 tests, 76,205 assertions, 30 skips**. Full PHP 8.3: **8,167 tests, 76,207 assertions, two existing PHPUnit E_ERROR warnings, 30 skips**.
- PHPStan, 527-file style, strict Composer validation and diff checks pass. Generated map agrees exactly at **231 entries**; SendGrid's namespaced alias exposes the new accessors. No dependency/vendor/baseline/threshold changes. Exact-final-head CI results will be recorded in the MR and issue notes.
