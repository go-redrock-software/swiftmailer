## Design

Infection's `simple-phpunit --version` subprocess must inherit the normal-test deprecation policy through both CI jobs and both Composer entry points. Preserve the coverage-only override, isolated runner, deprecation baseline and MSI thresholds. Validate the local probe, merged CI configuration and actual nonempty mutation CI path in !11.

## Implementation

Both mutation CI jobs and both Composer mutation entry points export `max[direct]=0&baselineFile=./tests/deprecation-baseline.json`. Previously only the coverage command set an environment policy; Infection's children inherited the default fail-on-deprecation policy. Verified in pipeline 32587 / job 164506 and locally: the version probe exits 1 without the policy and 0 with it. Symfony's [bridge documentation](https://github.com/symfony/symfony-docs/blob/7.4/components/phpunit_bridge.rst) describes the default zero threshold and explicit per-category configuration.

The scheduled mutation job and Composer commands have the same missing child environment in source, so the fix covers them too. The actual CI execution probe uses the MR entry point; a scheduled full-project mutation run is not claimed as passing. Coverage overrides, runner paths and mutation thresholds are unchanged.

Local validation with the inherited policy: coverage passes 3,991 unit tests / 21,931 assertions; the two-file mutation probe executes 47 mutants (37 killed, 10 escaped, zero execution/syntax errors/timeouts/uncovered cases). It correctly exits 1 at 78.72% covered MSI against the unchanged 95% threshold. The ten survivors are tracked in #41 and #47. Strict Composer validation passes; linted merged CI YAML contains the normal-test policy on both mutation jobs.

Actual CI validation: [pipeline 32588 / job 164514](https://code.go-redrock.com/trac/swiftmailer/-/jobs/164514) at `a1791039` completes the version probe and executes the same 47 mutants, with identical results and no execution errors/timeouts. All six required jobs pass. The mutation threshold failure remains intentional evidence of the separately tracked survivor gaps.
