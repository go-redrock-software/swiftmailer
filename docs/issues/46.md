## Design

Infection's `simple-phpunit --version` subprocess must inherit the normal-test deprecation policy. Preserve the coverage-only override, isolated runner, deprecation baseline and MSI thresholds. Validate the local probe and actual nonempty mutation CI path in !11.

## Implementation

The MR mutation job exports `max[direct]=0&baselineFile=./tests/deprecation-baseline.json`. Previously only the coverage command set an environment policy; Infection's children inherited the default fail-on-deprecation policy. Verified in pipeline 32587 / job 164506 and locally: the version probe exits 1 without the policy and 0 with it. Symfony's [bridge documentation](https://github.com/symfony/symfony-docs/blob/7.4/components/phpunit_bridge.rst) describes the default zero threshold and explicit per-category configuration.

The scheduled mutation job has a different checkout strategy and remains outside this MR's validation. Audit it separately; do not claim its setup is verified by the MR pipeline.
