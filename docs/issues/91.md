## Implementation

### Changes and approach

- Expanded accepted-response replay coverage from 25 to 97 cases. Gmail and both SES transports now exercise 200/201/202 through plain, retry, failover and round-robin paths. Assertions check one wire request, no fallback delivery, failed recipients, detached terminal failures, caller client/strategy ownership and unchanged message bytes. A credential-request control preserves legitimate retries.
- Added 12 permanent native SDK contracts in `tests/compatibility/sdk.php`, with one fresh child process per case in normal PHPUnit. The harness runs with production dependencies only; all HTTP is synthetic and credentials are fixtures. Failure exits and case identity are checked; raw SDK exception graphs never enter the result output. File-backed child diagnostics prevent stderr pipe deadlocks.
- Added mandatory `sdk-compatibility` GitLab jobs on PHP 8.3 and 8.5 using lowest-resolvable production dependencies and separate vendor caches. Current-dependency contracts run through the existing PHPUnit matrix.
- Added `doc/regression-tests.md`, mapping all 37 original MRs and !38–!41 follow-ups to concrete tests/native checks, plus contributor instructions.
- Production code, dependency constraints/lockfile, deprecation baselines and mutation thresholds are unchanged.
