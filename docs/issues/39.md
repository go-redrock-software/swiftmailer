## Design

Audit all concrete API transports. Preserve visible headers independently of delivery addresses where the provider supports raw MIME/envelope fields. Implement supported overrides and reject unsupported overrides before any provider request rather than silently falling back to header recipients. Keep submitted counts consistent with actual payloads. Ensure SDK-based transports dispatch recipient-policy events with the effective envelope, restore modified messages and report failures.

Verify affected provider contracts against current official documentation. Cover different header/envelope recipients and senders, hidden recipients, immutable caller inputs, rejection and cleanup, and counts. Run the full PHP 8.3/8.5 suites and quality checks.

## Provider audit

In progress. Current local inspection shows all 18 AbstractHttpApiTransport subclasses ignore their doSend envelope argument in payload construction. Two SES transports dispatch no SendEvent at all; Gmail/Graph dispatch events without setting the supplied envelope. Postal/Mailgun raw APIs and SES raw content need contract verification before implementation.
