## Implementation Plan

### Approach
Implement the verified SMTP connection-decoration gaps from #30 as #72, alongside the directly related zero-credential bug #73. Keep the broader #30 provider-construction audit open. Base on !28.

### Changes
- Add SMTP-only leaf DSN parameters: positive whole-second `timeout`, `auth_mode` selecting an installed authenticator (case-insensitive), and `local_domain` for an ASCII hostname or valid IPv4/IPv6 address/literal. Omission preserves native defaults. Normalize IPs through the native local-domain setter; reject whitespace/control/command-injection input and malformed domains.
- Validate raw occurrences, canonical names, scalar types and duplicate/array aliases using PHP's configured query separators. Share this logic with the existing SendGrid tracking validation, retaining all its behavior and credential-safe errors. Mark new credential-bearing parser/constructor trace arguments sensitive.
- Preserve SMTP user/password by null presence rather than truthiness. Make the native AUTH handler authenticate the string username `0`, while preserving omitted/empty/false behavior. Keep existing automatic mechanism priority and explicit mechanism selection.
- Add configuration, rejection, wrapper/public-helper and trace-privacy tests. Add an isolated loopback SMTP fixture that observes real EHLO and AUTH PLAIN/LOGIN/XOAUTH2 bytes for normal/zero credentials, plus a bounded server response hold proving the configured I/O timeout without a tight elapsed-time assertion. No production provider or message delivery.
- Update DSN/sending/architecture docs and committed handoffs. Maintain #30's requirement map and explicit remaining provider/SDK design work.

### Acceptance Criteria
- All SMTP schemes, including provider aliases and retry/pool composition, apply options to connection initialization, EHLO and AUTH. Unconfigured DSNs preserve their defaults. The public mailer helper uses the same settings.
- Timeouts are strictly positive decimal integers within PHP's integer range; unknown modes and unsupported schemes reject before connection. Domain validation permits documented host/IP forms and rejects injected SMTP commands. Defaults and TLS options remain intact.
- Literal `0` credentials survive DSN construction and reach actual AUTH bytes; native explicitly configured username `0` also authenticates. Omitted/empty username still skips AUTH. Existing failure, terminal, recipient and decorator policies remain covered.
- Raw duplicate/array/normalized-name rejection works under default and semicolon-enabled PHP configurations; own factory trace frames do not expose fixture credentials. Existing SendGrid controls retain their 91-case coverage.
- Failing-before tests, focused manual mutations, full PHP 8.3/8.5 suites, PHPStan, style, Composer/map/alias/diff checks and six required exact-final-head CI checks. Record optional CI limits accurately. No dependency/vendor changes, added baseline suppressions, threshold relaxations or merge.

### Sources and Risks
Context7 resolved `/swiftmailer/swiftmailer` and retrieved official source/docs about SMTP authentication and timeout semantics. The current fork's setters, AUTH registry/selection and stream buffer are authoritative for implementation. The native timeout accepts integer seconds and affects connection/I/O; zero has inconsistent fallback behavior, so the new DSN option rejects it rather than promising unsupported zero semantics. The native registry includes PLAIN, LOGIN, CRAM-MD5, NTLM and XOAUTH2; validate against actual configured authenticators so custom registry entries can work too.

Protocol tests use loopback ephemeral ports and synthetic credentials. The timeout fixture closes its held connection after a bounded wait so a broken/default timeout cannot stall the suite. Preserve direct setter compatibility and avoid changing constructor signatures or authentication priority. Sharing query validation requires re-running existing tracking tests and own-frame privacy checks without relying on a fixed stack depth.

## Implementation

### Changes

- Added SMTP-only `timeout`, `auth_mode` and `local_domain` DSN controls. Timeouts are positive decimal whole seconds within PHP's integer range. Modes match actual installed authenticators, including custom registry entries, without changing the normal priority order. Greeting domains accept validated ASCII hostnames and IP/literal forms, normalized by the native setter.
- Shared canonical-name/scalar/occurrence validation with SendGrid tracking, using PHP's configured query separators. Unsupported schemes, ambiguous duplicates/arrays/aliases and malformed settings reject before connection. New credential-bearing inputs to private factory helpers are sensitive trace parameters; existing tracking privacy checks inspect own factory frames without relying on a fixed stack depth.
- Preserved SMTP credentials by null presence and repaired native string-zero username and explicit string-zero mechanism selection. The installed Nyholm 2.0.1 parser also loses raw zero credentials; a small factory adapter restores only literal zero through immutable `withUser`/`withPassword` calls after successful parsing. Query parsing and vendor files are unchanged. Encoded zero and the supported no-slashes form are covered.
- Added an isolated loopback server fixture and public regression suite. Updated DSN/sending/architecture documentation and the #30 requirements map. The raw metadata helper retains the dependency's representation; broader provider/SDK work remains open under #30.

### Validation

- Verified failing-before run: **97 cases, 93 assertion failures and four passing default/absent-username controls**. A separate explicit-zero-mechanism test also fails before its native guard repair. Final new suite: **112 tests / 391 assertions**, passing both with default separators and `arg_separator.input=&;`.
- All 19 SMTP schemes are configured without connecting. Five timeout forms, ten built-in mode spellings, seven host/IP forms, TLS/source-IP/UTF8 preservation, four public-helper/decorator paths, six zero-credential spellings and five unsupported schemes are covered.
- Twelve loopback transcripts inspect real PLAIN/LOGIN/XOAUTH2 bytes with normal and zero credentials. Four native username controls retain AUTH/skip behavior. A real held EHLO response confirms the one-second read timeout; the fixture closes its connection after a bounded wait so a broken 30-second default cannot stall the test. No tight elapsed-time assertion, provider connection or message delivery is used.
- Two child-process configurations (`&;` and `;`) verify all three options, zero credentials, duplicate rejection and a custom authenticator registry. They load the reflected factory implementation before normal eager aliases. Own-frame redaction checks include private values in raw query metadata and rejected settings. Existing SendGrid coverage remains **91 cases**; combined new/tracking focus is **203 tests / 992 assertions**.
- **21/21 focused manual mutations detected by assertion failures**: ignored options; zero/overflow timeouts; unknown authenticators; invalid domains; duplicate/name/separator validation; parser/factory zero loss; native zero guards; and five own-frame redaction inputs. Original snapshots restored. Child fixtures report ordinary configuration rejection as data, so semantic mutants are distinguished from parser/bootstrap errors. This is not an Infection MSI score.
- Wider helper/factory/auth/tracking focus: **357 tests / 1,491 assertions**, passing. Full PHP 8.5: **8,313 tests, 76,840 assertions, 30 skips**. Full PHP 8.3: **8,313 tests, 76,845 assertions, two existing PHPUnit E_ERROR warnings, 30 skips**.

No dependency/vendor/baseline/threshold changes. Exact-final-head CI results will be recorded in the MR and issue notes.
